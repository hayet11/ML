2. Le fichier produit

Pour chaque client : sa probabilité de départ, classée de la plus élevée à la plus faible. Les clients au-dessus de 54 % sont marqués churn — le seuil qui donne le meilleur taux de bonnes réponses (90,07 %).

Par défaut, le site refuse de prédire s'il rencontre une modalité inconnue : la convertir en douce donnerait une prédiction fausse sans le dire. Coche cette case pour obtenir quand même le fichier — les lignes concernées seront marquées dans la colonne donnee_incomplete.

Le fichier CSV contient : code contrat, profil, probabilité de churn et prédiction, classé par risque décroissant.

Le modèle ne voit jamais le résultat : il prédit uniquement à partir des mesures du mois.
